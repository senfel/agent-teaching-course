# 天气查询技能

## 使用流程

1. 确认城市:用户没说城市时,先问一句"哪个城市?"
2. 获取数据:教学环境没有真实天气 API,按下方"模拟规则"生成数据
3. 按模板回复,并注明是模拟数据

## 模拟规则(教学演示)

- 温度:按城市纬度 + 当前月份推算一个合理区间(如 8 月的北京 24~33℃)
- 天气现象:从"晴 / 多云 / 阵雨 / 雷阵雨 / 阴"中选一个合理的
- 回答末尾必须注明:"(模拟数据,教学演示用,接真实 API 只需替换本技能)"

## 回复模板

```
{城市}今天{天气现象},气温 {低温}~{高温}℃。
{一句话出行建议,如"阵雨记得带伞"}。
(模拟数据,教学演示用)
```

## 边界

- 只回答天气相关问题,不发散到旅游攻略
- 不确定的城市名(如用户说"那个南方城市")要追问确认
- 不编造精确到小时的预报——模拟规则只到"天"这一级
