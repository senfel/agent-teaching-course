# 第 01 期 · 知识卡片:LLM vs Agent

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│           LLM vs Agent —— 一句话讲清区别                     │
│                                                             │
│   ┌─────────────────┐         ┌─────────────────────┐       │
│   │                 │         │                     │       │
│   │      LLM        │         │      Agent          │       │
```
