## 本期三个核心概念

1. **MODEL_REGISTRY(模型注册表)** — 模型池的"价目表":每个模型记录 tier(light/heavy 档)、input/output 单价($/百万 token)、强项、api_model(真实端点名)。换模型、调价只改这里
2. **路由器(route_model / resolve_model)** — 决定本次调用用谁:manual 钉住优先 → 后台任务固定 light 档 → auto 规则(命中复杂关键词或消息超 400 字符 → heavy,否则 light)。每个决策带 reason,记入路由历史
3. **成本 telemetry(log_usage)** — 每次调用的计价器:`cost = prompt_tokens/1e6 × input_price + completion_tokens/1e6 × output_price`,追加落盘 usage_log.jsonl

## 四条路由路径

```
auto·规则    命中关键词(审查/分析/设计/对比/debug/优化/...)或消息>400字符 → heavy(deepseek-reasoner)
auto·默认    简单任务:无关键词、消息不长                    → light(deepseek-chat)
background   compact 压缩 / 子代理 / 队友调用                → 固定 light 档(省钱策略)
manual       用户钉住某模型(switch_model)                   → 钉住的模型,直到切回 auto
```

> 后台任务为什么不路由?compact/子代理/队友都是受限小任务,旗舰推理力用不上——固定便宜档,路由策略本身就是省钱策略。

## 一行代码记住本期

```python
# 所有 LLM 调用的统一入口:路由在前,记账在后
def llm_call(messages, task="main", tools=None, max_tokens=4096):
    model_id, reason = resolve_model(messages, task=task)   # ① 路由:选模型
    api_model = MODEL_REGISTRY[model_id]["api_model"]       #    逻辑名 → 端点名
    response = client.chat.completions.create(model=api_model, messages=messages, ...)
    log_usage(model_id, response.usage.prompt_tokens,       # ③ 记账:算成本
              response.usage.completion_tokens, task)       #    → usage_log.jsonl
    return response, model_id
```
