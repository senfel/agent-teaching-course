# 用户画像(User Profile)

> 跨会话长期记忆。本文件由 Agent 在每次对话后**自动更新**,
> 记录用户的稳定偏好、角色、背景信息,下次启动会被加载到 system prompt。

---

## 基础信息

- **角色**:张三,创业公司 CTO
- **技术栈**:Python(主力)、TypeScript、Go(学习中)
- **常用编辑器**:VS Code + Vim 模式
- **操作系统**:macOS

---

## 稳定偏好

- **代码风格**:类型注解完整、函数不超过 50 行、变量名用英文
- **回答风格**:简洁、直接、不要寒暄,代码 > 长段文字
- **Python 版本**:3.12(全项目统一)
- **包管理**:uv(已全面替代 pip + venv)

## 工作背景

- 正在搭建一套 AI Agent 教学课程(15 期)
- 当前进度:第 07 期 · 记忆系统
- 团队规模:小(2-5 人),节奏快
- 关注点:可维护性 > 性能,可读性 > 巧妙

---

## 已知反偏好

- 不要用 emoji 装饰代码注释
- 不要在每段回答末尾追加"还有什么需要帮忙的吗"
- 不要"亲""宝子"等称呼
- 不要解释显而易见的事(例如"print 会打印输出")

_下次启动时,此文件会被注入 system prompt,作为"长期记忆"使用。_
