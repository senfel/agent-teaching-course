# 历史压缩提示词(Compact Prompt)

> 当对话历史超过阈值时,用此提示词让模型把早期对话"压缩"成摘要,
> 再用摘要替换原始 messages,腾出上下文窗口。

你的任务是把下面的对话历史**压缩成简洁的第三人称摘要**,保留关键信息。

## 必须保留

1. **用户的关键偏好和决策**(如"用 Python 3.12""类型注解必须完整")
2. **已经达成一致的事实**(如"项目名是 X""选型 Y")
3. **未完成的任务**(如"下一步要部署到 Docker")
4. **用户提到的具体数字、命令、文件名**
5. **最后 1-2 轮的核心结论**

## 必须省略

1. 寒暄、客套话、重复的问题
2. 已完成的工具调用细节(除非结论重要)
3. 模型回答中的长篇代码(只保留文件名和关键函数名)
4. 与主线无关的闲聊

## 输出格式

```
【时间范围】YYYY-MM-DD ~ YYYY-MM-DD
【核心事实】3-5 条要点
【用户偏好】2-3 条明确表态
【未完成任务】1-3 条 TODO
【关键引用】文件名 / 命令 / 数字
```

只输出摘要,不要前缀解释。摘要不超过 500 字。
