CONCEPT
02 / 10

LLM vs Agent —— 别再混着用

🧠 LLM

大语言模型,输入文本/图像/音频
输出文本(多模态:GPT-4o 看图、Gemini 听声音)

只会"生成",无记忆、无手脚

类比:博学但无手脚的顾问

🤖 Agent

以 LLM 为大脑,能调工具、保记忆、自主循环

能"说"也能"做"

类比:有手有脚的助理

后续 14 期 = 给 LLM 装上 手脚 和 脑子

很多人把这两个概念混着用,但它们不是一回事。LLM 只会"说",你问它什么它都能答,但它没法替你查文件、没法替你发邮件。

SETUP
06 / 10

本地环境 · 4 条命令

先装 Python 3.10+:python.org 下载,Windows 务必勾 Add to PATH。再用虚拟环境锁依赖,不污染系统。

macOS / Linux

# 1. 创建(只需一次)
python3 -m venv .venv

# 2. 激活(每次开终端都做)
source .venv/bin/activate

# 3. 装依赖
pip install -r requirements.txt

# 4. 配 Key
cp .env.example .env

Windows(PowerShell)

# 1. 创建(只需一次)
python -m venv .venv

# 2. 激活(每次开终端都做)
.venv\Scripts\activate

# 3. 装依赖
pip install -r requirements.txt

# 4. 配 Key
copy .env.example .env

激活成功提示符前会出现 (.venv)。若直接跑报 No module named 'dotenv',说明忘了激活;Windows 激活报"禁止运行脚本",执行一次 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned。

FIRST CALL
07 / 10

第一次调用 · 6 行代码

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],
    base_url="https://api.deepseek.com",   # ← 关键
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)

DeepSeek 兼容 OpenAI 协议,改 base_url 即可。

运行 python code/step01_hello_agent.py 后,程序会自动问 3 个问题感受能力,然后进入自由对话模式(用 prompt_toolkit,退格/光标/历史都正常,输错按 Ctrl-C 作废本行不退出)。
