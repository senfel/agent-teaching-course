SCHEMA
05 / 11

用 JSON Schema 描述工具

TOOLS = [
  {
    "type": "function",
    "function": {
      "name": "get_current_time",
      "description": "获取当前日期和时间。当用户问'现在几点'时调用。",
      "parameters": {
        "type": "object",
        "properties": {
          "timezone": { "type": "string", "description": "时区" }
        },
        "required": []
      }
    }
  }
]

模型看到 description 和 parameters,据此判断何时调用、传什么参数。

本期装了 2 个工具:get_current_time(拿时间) + calculate(四则运算)

CORE
06 / 11

工具循环 · 模型决定 → 执行 → 喂回去

user: "现在几点了?"
↓ 第 1 次调用 API(tools=TOOLS, tool_choice=auto)
assistant: tool_calls=[get_current_time()] ← 模型说"我要调工具"
↓ 执行工具: datetime.now() → {"datetime": "2026-08-14 15:30:00", ...}
tool: {"datetime": "2026-08-14 15:30:00", "weekday": "周四"} ← 结果喂回去
↓ 第 2 次调用 API(带着工具结果)
assistant: "现在是 2026年8月14日 15:30,周四。" ← 最终回答

关键:不再是"一问一答"单次调用,而是一个循环。模型先说"我要调工具",执行后喂回去,再调一次让模型生成最终回答。

CODE
07 / 11

核心代码 · 工具循环

def chat_with_tools(messages):
    while True:
        response = client.chat.completions.create(
            model=MODEL, messages=messages,
            tools=TOOLS,              # ← 告诉模型有哪些工具
            tool_choice="auto",        # ← 模型自己决定要不要调
        )
        msg = response.choices[0].message

        if msg.tool_calls:           # ← 模型决定调工具
            messages.append({"role": "assistant", "tool_calls": [...]})
            for tc in msg.tool_calls:
                result = execute_tool(tc.function.name, ...)
                messages.append({"role": "tool", "content": result})
            continue              # ← 继续循环,让模型生成最终回答

        return msg.content      # ← 模型返回文本,循环结束

tool_choice="auto":模型判断问时间就调工具,问"你好"就不调。

SECURITY
09 / 11

安全性 · 工具执行不可信输入

危险:eval()

# 模型传入恶意表达式
expr = "__import__('os').system('rm -rf /')"
result = eval(expr)  # 💀 任意代码执行

模型传来的参数不可信!

安全:AST 解析

import ast, operator

tree = ast.parse(expr, mode="eval")
result = _safe_eval(tree.body)
# 只允许 Num / BinOp / UnaryOp
# 其他节点直接报错

只允许四则运算,拒绝任意代码

工具执行是 Agent 安全的关键——execute_tool() 是代码边界,模型参数必须当作用户输入来校验。

TRY IT
10 / 11

试一试 · 6 个动手实验

  • 问时间 — 输入"现在几点了?今天星期几?"
    看模型调用 get_current_time,打印调用过程和结果
  • 问计算 — 输入"帮我算 17 * 23"
    看模型调用 calculate,这次不会再心算出错
  • 纯聊天 — 输入"你好"或"Python 怎么读文件"
    看模型不调工具直接回答——tool_choice=auto 让模型自己判断
  • 输入 tools — 打印已装工具列表
    直观看到 JSON schema 描述长什么样
  • 输入 history — 打印 messages 列表
    看工具循环留下的痕迹:assistant 带 tool_calls、tool 结果、最终回答
  • 思考题 — 工具执行出错会怎样?
    模型拿到 error 后会怎么处理?(代码里 calculate 已做错误处理)
